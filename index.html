使用帮助

连接设备步骤：

  1. 确保 ESP 设备通过 USB 连接到电脑
  2. 点击"连接 ESP 设备"按钮
  3. 在弹出的对话框中选择正确的串口设备
  4. 可能需要按下 ESP 设备的 BOOT 按钮进入下载模式

支持的浏览器：

  • Chrome 89 及以上版本
  • Edge 89 及以上版本
  • Opera 76 及以上版本

常见问题：

  • 无法连接设备？ 检查 USB 连接，尝试重新插拔
  • 烧录失败？ 确保选择了正确的 Flash 配置
  • 设备无响应？ 尝试手动进入下载模式
